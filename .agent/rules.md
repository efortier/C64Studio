## Rules

Always modify Designer.cs directly for UI additions.

When adding new functionality to the export, make sure it is available in all codepaths.

When adding a new setting for the MapEditor, make sure to save/load it in the map file.

When exporting as assembly, make sure to follow all the export settings, for example the use of semicolon or not, export as hez or not, the string for labels and bytes, etc.
