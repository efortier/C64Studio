# Visual controls

This skill is used to change or add visual controls to the application.

## When to use this skill

1. Use this when the user explicitly requests a change or addition of a visual control to the application.

## Modification checklist

1. Identify the files that need to be modified. Focus on the files that are most relevant to the user's request and the files that are modified but not yet committed.
2. When adding a new control, unless explicitly requested by the user, add it as a visual control to the default theme.
3. When modifying an existing control, unless explicitly requested by the user, modify it as a visual control to the default theme.
4. Once the code is built and the functionality is verified, perform a code review to make sure the code is correct and satisfies the user's needs.

## How to provide feedback

- Explain what changed and why.
