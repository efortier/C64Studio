# Modify functionality

This skill is used to modify the functionality of existing code.

## When to use this skill

1. Use this when the user explicitly requests a modification of the existing code.

## Modification checklist

1. Identify the code snippets or files that need to be modified. Focus on the code that is most relevant to the user's request and the code that is modified but not yet committed.
2. Thoroughly analyze the existing code as it related to the code that needs to be modified. This includes the code that is most relevant to the user's request.
3. Analyze the code for logical correctness, performance bottlenecks, and adherence to the project's coding style.
4. Clarify the user's request and ensure that the code is modified in a way that satisfies the user's needs, taking into account the impact of other functions by implementing the changes.
5. Once the code is modified, build the project to make sure there's no build errors. (.NET 3.5 build errors are expected and should be ignored)
6. Once the code is built and the functionality is verified, perform a code review to make sure the code is correct and satisfies the user's needs.

## How to provide feedback

- Explain what changed and why.
